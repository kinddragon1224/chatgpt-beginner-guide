# 2장 · Chat

**묻고, 설명 듣고, 아이디어를 모으며, 짧은 글을 쓰고, 고치고, 맞춤을 맞추고, 이미지도 만듭니다.**

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt.md)

Chat은 「한 번의 완성본」보다 **묻고 답하고 고치기**입니다. 질문하고, 부족한 조건을 덧붙이고, 「더 짧게」「다른 각도 세 가지」처럼 방향을 바꿉니다.

Work으로 넘기기 전에, Chat만으로도 「쓸 만한 문장」까지 가는 감각을 만듭니다.

회사 메신저·가정 카톡·교회 주보 안내처럼, 한국 성인의 하루에서 끝내는 일입니다.

| 레슨 | 내용 |
|------|------|
| 2-1 | 질문하기 — 목적·조건·형식을 한 번에 |
| 2-2 | 설명 요청하기 — 내가 아는 정도에 맞춰 |
| 2-3 | 브레인스토름 — 선택지를 넓힌 뒤 고르기 |
| 2-4 | 짧은 초안 쓰기 — 메시지·안내문 수준의 글 |
| 2-5 | 대화로 고쳐 쓰기 — 같은 채팅에서 한 가지씩 수정 |
| 2-6 | 개인 맞춤 설정 — 성격·맞춤 지시 |
| 2-7 | 이미지 만들기 — 한 장 만들고 한 번 고치기 |

나쁜 예와 좋은 예, 답을 어떻게 쓸지까지 적었습니다. **한 레슨에 한 행동**만 끝내고 멈추세요.
