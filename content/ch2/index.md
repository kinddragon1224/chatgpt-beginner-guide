# 2장 · Chat

**묻고, 설명 듣고, 아이디어를 모으고, 짧은 글을 쓰고 고칩니다. 말투를 맞추고 그림도 만들어 봅니다.**

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt)

Chat은 한 번에 완성본을 받는 곳이 아닙니다. **묻고, 답을 보고, 고치는 곳**입니다. 질문하고, 모자란 조건을 보태고, 「더 짧게」「다른 방향으로 세 가지」처럼 방향을 바꿉니다.

2장은 Chat만 씁니다. 카톡 안내, 교회 주보, 병원 예약 문자처럼 하루 안에 끝나는 일을 합니다.

| 레슨 | 내용 |
|------|------|
| 2-1 | 질문하기 — 목적·조건·형식을 한 번에 |
| 2-2 | 설명 요청하기 — 내가 아는 만큼에 맞춰 |
| 2-3 | 아이디어 모으기 — 넓게 받은 뒤 고르기 |
| 2-4 | 짧은 초안 쓰기 — 문자·안내문 길이로 |
| 2-5 | 대화로 고쳐 쓰기 — 같은 채팅에서 한 가지씩 |
| 2-6 | 개인 맞춤 설정 — 말투를 한 번 맞춰 두기 |
| 2-7 | 이미지 만들기 — 한 장 만들고 한 번 고치기 |

레슨마다 나쁜 예와 좋은 예가 있습니다. **한 레슨에 한 행동**만 끝내고 멈추세요. 2장은 2-7까지 가야 끝납니다.
