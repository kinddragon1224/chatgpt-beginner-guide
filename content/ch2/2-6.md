# 2-6 · 개인 맞춤 설정

공식: [Personalize ChatGPT](https://learn.chatgpt.com/docs/personalize) · [Settings](https://learn.chatgpt.com/docs/reference/settings)

## 준비운동

매번 「짧게, 존댓말, 이모지 없이」라고 적기 귀찮죠. **한 번만 맞춰 두면** 다음 채팅에도 따라옵니다.

이 레슨에서는 설정에서 **성격(Personality)** 과 **맞춤 지시(Custom instructions)** 만 건드립니다. 기억(Memories)·컴퓨터 기록 같은 고급 항목은 「있다」 정도만 알아 둡니다. 웹과 데스크톱에 보이는 메뉴가 조금 다를 수 있습니다.

## 어디 보면 되나

```
[프로필 · 설정 / Settings]
  → Personalization / 개인 맞춤
     · Personality (Friendly / Pragmatic / None 등)
     · Custom instructions / 맞춤 지시
     · Memories (있으면)
```

웹에서는 보통 왼쪽 아래 **프로필 사진·이름** → **Settings(설정)** 입니다.  
데스크톱 앱은 메뉴의 Settings, 또는 macOS `Cmd+,` / Windows `Ctrl+,` 로 열리는 경우가 많습니다.

메뉴 글자가 번역되어 있어도 「설정」「개인화」「맞춤」에 가까운 곳을 찾으면 됩니다.

## 이렇게 해 보세요

1. ChatGPT를 연 뒤 **설정(Settings)** 으로 들어갑니다.
2. **Personalization / 개인 맞춤** 을 엽니다.
3. **Personality** 가 있으면 하나를 고릅니다.  
   - Friendly — 말투가 더 다정합니다.  
   - Pragmatic — 실무·단답형입니다.  
   - None — 성격 지시를 끕니다.  
   능력(무엇을 할 수 있는지)이 바뀌는 게 아니라, **말하는 방식**이 바뀝니다.
4. **Custom instructions / 맞춤 지시**에 한국어로 두세 줄만 적어 봅니다. 예:

> 답은 한국어로, 존댓말. 이모지 없이. 먼저 한 줄 요약, 그다음 짧은 목록. 추측하지 말고 모르면 모른다고 하세요.

5. 저장한 뒤 **새 Chat**을 열고, 아무 질문이나 하나 보냅니다.  
   예: 「주말에 집 근처 산책 코스를 짧게 추천해 주세요.」
6. 답이 맞춤 지시와 비슷한지 봅니다. 너무 길면 지시문에 「다섯 줄 이내」를 더합니다.

## 이 정도면 됐어요

설정에서 개인 맞춤 메뉴를 열 수 있고, **성격 하나**와 **맞춤 지시 몇 줄**을 저장해 새 채팅에서 느낌이 바뀌는지만 확인하면 됩니다.

## 막히면

- 메뉴가 안 보이면 프로필·계정·…(더보기)를 한 바퀴만 둘러보세요.
- Memories·Writing style·Computer History는 **없어도 건너뛰세요**. 회사 계정은 관리자가 막아 둘 수 있습니다.
- 맞춤 지시를 너무 길게 쓰지 마세요. 두세 줄이 낫습니다.
- 유튜브에 「ChatGPT 맞춤 설정」「ChatGPT custom instructions」를 검색해 천천히 따라가도 됩니다.
