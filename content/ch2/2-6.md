# 2-6 · 개인 맞춤 설정

공식: [Personalize ChatGPT](https://learn.chatgpt.com/docs/personalize) · [Settings](https://learn.chatgpt.com/docs/reference/settings)

## 준비운동

매번 「짧게, 존댓말로, 이모지 없이」라고 쓰기 번거롭죠. **한 번만 맞춰 두면** 다음 채팅에도 그대로 따라옵니다.

이 레슨에서는 설정에서 **성격**(Personality)과 **맞춤 지시**(Custom instructions) 두 가지만 만집니다. 다른 항목은 건드리지 않습니다. 웹과 데스크톱은 메뉴가 조금 다르게 보일 수 있습니다.

## 어디 보면 되나

```
[프로필 · 설정 / Settings]
  → Personalization / 개인 맞춤
     · Personality (Friendly / Pragmatic / None 등)
     · Custom instructions / 맞춤 지시
     · Memories (있으면)
```

웹에서는 보통 왼쪽 아래 **프로필 사진·이름** → **Settings**(설정)입니다.  
데스크톱 앱은 메뉴의 Settings, 또는 macOS `Cmd+,` / Windows `Ctrl+,`로 열리는 경우가 많습니다.

메뉴 글자가 한국어로 바뀌어 있어도 「설정」「개인화」「맞춤」 비슷한 곳을 찾으면 됩니다.

## 이렇게 해 보세요

1. ChatGPT를 열고 **설정**(Settings)에 들어갑니다.
2. **Personalization / 개인 맞춤**을 엽니다.
3. **Personality**가 있으면 하나를 고릅니다.  
   - Friendly — 말투가 더 다정합니다.  
   - Pragmatic — 짧고 실용적입니다.  
   - None — 성격 설정을 끕니다.  
   할 수 있는 일이 바뀌는 게 아니라 **말하는 방식**이 바뀝니다.
4. **Custom instructions / 맞춤 지시**에 한국어로 두세 줄만 써 봅니다. 예:

> 답은 한국어 존댓말로 해 주세요. 이모지는 넣지 마세요. 먼저 한 줄로 요약하고, 그다음 짧은 목록으로 보여 주세요. 모르면 모른다고 해 주세요.

5. 저장한 뒤 **새 채팅**을 열고 아무 질문이나 하나 보냅니다. 예: 「주말에 집 근처에서 걷기 좋은 코스를 짧게 추천해 주세요.」
6. 답이 맞춤 지시대로 오는지 봅니다. 너무 길면 지시에 「다섯 줄 이내」를 보탭니다.

## 이 정도면 됐어요

개인 맞춤 메뉴를 열었고, **성격 하나**와 **맞춤 지시 몇 줄**을 저장한 뒤 새 채팅에서 말투가 바뀌는지 봤으면 됩니다.

## 막히면

- 메뉴가 안 보이면 프로필·계정·…(더보기)를 한 바퀴만 둘러봅니다.
- 다른 항목은 없거나 잠겨 있어도 건너뜁니다. 회사 계정은 관리자가 막아 둘 때가 있습니다.
- 맞춤 지시는 길게 쓰지 마세요. 두세 줄이 낫습니다.
- 유튜브에서 「ChatGPT 맞춤 설정」을 검색해 천천히 따라가도 됩니다.
