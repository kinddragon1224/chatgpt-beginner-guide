# 2-1 · 질문하기

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt)

## 준비운동

좋은 질문은 화려한 문장이 아닙니다. **무엇 때문에(목적), 어떤 조건에서(조건), 어떤 모양으로(형식)** 받고 싶은지가 들어간 질문입니다. 「알려 줘」만 보내면 답은 길기만 하고 쓸 데가 적습니다.

흔한 실수가 두 가지 있습니다. 상황을 너무 줄여서 「그냥 추천해 줘」라고 보내는 것. 한 번에 열 가지를 몰아서 묻는 것.

오늘은 Chat에 **분명한 질문 하나**를 보내고, 필요하면 조건을 **한 번만** 보탭니다.

## 어디 보면 되나

```
[위쪽] Chat
[아래] 입력창
[대화] 내 질문 → 답 → (필요하면) 한 줄 더
```

왼쪽 대화 목록에 비슷한 주제가 있어도, **새 채팅**을 여는 편이 덜 헷갈립니다.

## 이렇게 해 보세요

1. 새 채팅을 엽니다.
2. 나쁜 예와 좋은 예를 읽고, 내 주제로 바꿔 보냅니다.

**나쁜 예**

> 나들이 추천해 줘.

**좋은 예**

> 이번 주말에 부부 둘이 갈 나들이 장소를 찾습니다. 서울에서 지하철로 한 시간 안, 많이 걷지 않는 곳이면 좋겠습니다. 후보 다섯 곳을 표로 정리하고, 곳마다 한 줄 이유를 붙여 주세요. 여는 시간과 입장료가 확실하지 않으면 ‘확인 필요’라고 써 주세요.

업무라면 「다음 주 팀 회의 안건 네 개와 안건별 시간을 표로」처럼 같은 틀로 씁니다.

3. 답이 다 나올 때까지 기다립니다. 그동안 다른 채팅을 열지 않습니다.
4. 필요할 때만 **한 줄**을 더 보냅니다. 예: 「무릎이 안 좋습니다. 계단 없는 곳 두 곳만 남겨 주세요.」 세 번 넘게 보내지는 마세요. 조건이 크게 바뀌면 새 채팅이 낫습니다.
5. 표가 마음에 들면 복사해 둡니다. 답 아래 작은 아이콘 가운데 **복사** 버튼을 누르고, 카톡 입력칸을 길게 눌러 **붙여 넣기**를 고릅니다. 복사 버튼을 못 찾으면 글자를 길게 눌러(컴퓨터는 마우스로 끌어서) 복사해도 됩니다.

## 이 정도면 됐어요

질문 하나에 목적·조건·형식이 들어갔고, 답이 그 모양(표·목록)으로 왔으면 됩니다. 여는 시간·주소 같은 숫자는 그곳 홈페이지나 지도 앱에서 한 번 더 확인합니다. 「추천 1위」를 그대로 믿고 나서지 마세요.

## 막히면

| 이럴 때 | 이렇게 |
|------|------|
| 답이 너무 길다 | 「세 문단으로」「표로만」「점 목록 다섯 줄」처럼 **모양만** 다시 말하기 |
| 질문이 너무 넓다 | 지역·인원·예산·날짜 가운데 **숫자 하나** 보태기 |
| 사실이 의심된다 | 여는 시간·요금·법은 공식 홈페이지에서 다시 보기. 「추측하지 말고 ‘확인 필요’로」 |
| Work로 잘못 들어갔다 | 위쪽 전환에서 Chat으로 바꾸고 다시 보내기 |

병원·법·세금·돈 문제의 결정은 전문가와 공식 기관을 따릅니다. ChatGPT는 생각을 돕는 도구입니다.
