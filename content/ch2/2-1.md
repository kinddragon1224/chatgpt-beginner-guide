# 2-1 · 질문하기

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt.md)

## 준비운동

좋은 질문이란 화려한 문장이 아닙니다. **목적·조건·형식**이 드러난 질문입니다. 「알려 줘」만 있으면 답은 길기만 하고 쓸모가 줄어듭니다.

한국에서 흔한 실수 두 가지입니다. 상황을 너무 짧게 줄이고 「그냥 추천해 줘」라고 보내는 것. 한 질문에 열 가지를 몰아넣어 답이 산만해지는 것.

Chat에서 **한 번의 분명한 질문**을 보내고, 필요하면 **한 번만** 조건을 보탭니다. 파일은 만들지 않습니다.

## 어디 보면 되나

```
[위쪽] Chat
[아래] 입력창
[대화 영역] 내 질문 → 답 → (선택) 후속 한 줄
```

왼쪽 최근 대화 목록에 비슷한 주제가 있어도, **새 채팅**을 여는 편이 헷갈림이 적습니다.

## 이렇게 해 보세요

1. **Chat**으로 새 채팅을 엽니다.
2. 아래 **나쁜 예 / 좋은 예**를 읽고, 자신의 주제로 바꿔 입력합니다.

**나쁜 예 (피하세요)**

> 나들이 추천해 줘.

**좋은 예 (목적·조건·형식)**

> 주말 가족 나들이를 계획합니다. 서울에서 대중교통으로 왕복 3시간 안, 실내 위주, 아이 포함 4명입니다. 후보지 다섯 곳을 표로 정리하고, 각 장소에 한 줄 이유를 붙여 주세요. 영업시간·요금은 확실하지 않으면 ‘확인 필요’로 남기세요.

업무용으로 바꾸면 예를 들어 이렇게입니다.

> 다음 주 화요일 1시간 팀 회의 안건을 잡습니다. 참석 6명, 안건은 ‘분기 목표 진행률’과 ‘고객 문의 병목’ 두 가지입니다. 안건 제목 네 개와 각 안건별 논의 시간(분)을 표로 주세요. 회의록 초안은 아직 필요 없습니다.

3. 보냅니다. 답이 오는 동안 다른 채팅을 열지 마세요.
4. 답이 끝나면, 필요할 때만 **한 줄 후속**을 보냅니다. 예: 「아이가 초등학생입니다. 그에 맞게 두 곳만 남기고 다시 정리해 주세요.」 후속을 세 번 이상 보내지 마세요. 조건이 크게 바뀌면 새 채팅이 낫습니다.

## 답이 오면

- 표·목록이 오면 **복사해 메모장·노션·메일 초안**에 붙인 뒤, 숫자·주소만 공식 사이트에서 확인합니다.
- 「추천 1위」를 그대로 예약하지 마세요. Chat은 후보를 넓혀 주는 도구이지, 예약 대행이 아닙니다.
- 업무 안건이면 표만 팀 메신저에 올리고, 「이 중 무엇을 뺄까」는 사람이 결정합니다.

## 이 정도면 됐어요

질문 하나에 **누구를 위한 일인지·제약·원하는 형식**이 들어갔고, 답이 그 형식(표·목록 등)으로 돌아왔으면 됩니다. 「완벽한 답」이 목표가 아닙니다.

## 막히면

| 증상 | 대처 |
|------|------|
| 답이 장황하다 | 「세 문단으로」「표로만」「불릿 다섯 개」처럼 **형식만** 다시 지정 |
| 질문이 너무 넓다 | 지역·인원·예산·기한 중 **숫자 하나**를 추가 |
| 사실이 의심된다 | 영업시간·요금·법규는 공식 사이트 재확인. 「추측하지 말고 확인 필요로」 |
| Work으로 잘못 들어갔다 | 위쪽 전환에서 Chat으로 바꾼 뒤 같은 질문을 다시 |

의료·법률·세무·인사 결정은 전문가·사내 규정을 따릅니다. ChatGPT는 판단의 보조입니다.
