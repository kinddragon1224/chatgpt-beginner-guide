# 2-2 · 설명 요청하기

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt.md)

## 준비운동

설명 요청은 「검색 결과 요약」과 다릅니다. 검색은 링크와 제목을 주고, Chat은 **내가 아는 정도**를 밝히면 그 수준에 맞춰 다시 말해 줍니다.

**비유·예시·자주 하는 오해**를 요청하면 이해 속도가 달라집니다.

직장·학원·가정에서 자주 막히는 지점은 「클라우드」「개인정보」「부가세」처럼 뉴스에는 나오지만 정의가 흐린 말입니다. 전문 용어 하나를 골라, 암기가 아니라 **말로 다시 설명할 수 있을 정도**까지 갑니다.

## 어디 보면 되나

```
[Chat]
[입력창] 개념 + 내 수준 + 원하는 설명 방식
[답] 정의 → 비유 → 예시 → 자주 하는 오해
[후속] 이해가 안 된 문장 하나만 집어 「이 문장만 더 쉽게」
```

## 이렇게 해 보세요

1. Chat에서 새 채팅(또는 2-1과 주제가 이어지면 같은 채팅)을 엽니다.
2. 아래 틀을 채웁니다. 주제는 업무·취미·뉴스 중 하나로 바꿉니다.

**나쁜 예**

> 클라우드가 뭐야?

**좋은 예**

> 「클라우드」가 무엇인지 설명해 주세요. 저는 IT 전문가가 아닙니다.  
> 1) 두 문장 정의, 2) 일상 비유 하나, 3) 회사에서 쓰는 구체 예 하나, 4) 사람들이 자주 헷갈리는 점 하나를 순서대로 적어 주세요.  
> 전문 용어가 나오면 괄호 안에 쉬운 말을 붙여 주세요.

학습용으로 바꾸면 예를 들어 이렇게입니다.

> 「상관관계와 인과관계」 차이를 직장인 교양 수준으로 설명해 주세요.  
> 정의 두 문장, 일상 비유 하나, 「상관만 있고 인과는 아닌」 예시 하나, 「둘 다 있는」 예시 하나를 주세요. 수식은 넣지 마세요.

생활·금융이라면 「연말정산」「실손보험」처럼 **본인이 곧 결정을 앞둔 말**을 고르세요. 다만 설명은 설명일 뿐, 세무·보험 가입 결정은 상담사·국세청 안내를 따릅니다.

3. 보냅니다.
4. 이해가 안 되는 문장 하나만 집어 「이 문장만 더 쉽게. 비유를 바꿔 주세요.」라고 후속합니다. 전체를 「처음부터 다시」 하지 마세요. **한 문장만** 고치는 습관이 2-5로 이어집니다.

## 답이 오면

- 답을 읽고, **남에게 30초로 설명**해 보세요. 막히는 단어가 남으면 그 단어만 후속으로 묻습니다.
- 업무 용어라면 팀 메모에 「우리 팀 말」로 한 줄 요약해 둡니다. Chat 원문을 그대로 붙여 넣지 말고, 사실 확인 후 자기 문장으로 바꿉니다.
- 뉴스 용어라면 「내가 이해한 것 / 아직 모르는 것」 두 줄만 메모합니다.

## 이 정도면 됐어요

답이 **정의·비유·예시·오해** 순으로 정리되어 있고, 모르는 문장을 한 번 더 풀어 달라고 할 수 있으면 됩니다. 암기할 필요는 없습니다.

## 막히면

설명이 여전히 어렵으면 「중학생에게 말하듯」「비유만 두 개」「전문 용어 없이」처럼 제약을 좁히세요. 반대로 너무 유치하면 「성인 교양 수준으로, 유치한 비유는 빼 주세요」라고 하세요.

의료·법률·세무·투자처럼 책임이 큰 주제는 **전문가·공식 기관 확인**이 필요합니다. 설명을 「확정된 조언」으로 쓰지 마세요.

답이 영어 위주면 「같은 내용을 한국어로, 외래어는 최소화」라고 한 번만 후속합니다.
