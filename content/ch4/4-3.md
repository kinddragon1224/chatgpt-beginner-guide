# 4-3 · 없어도 되는 날, 있어도 되는 날

## 준비운동

기능을 「전부 설치하라」고 몰아치면, 안 열리는 화면 앞에서 자신을 탓하기 쉽습니다. 교실에서도 「옆 사람 화면엔 있는데」로 주눅 드는 분이 있습니다.

4장은 말합니다. **없어도 된다.** 없어도 책을 마칠 수 있고, 있으면 같은 일을 더 적게 복사·붙여 넣어 끝냅니다.

## 점검표만 보세요

새 메뉴는 안 찾습니다. 아래만 봅니다.

```
[ ] Plugins 메뉴가 있다
[ ] @ 메뉴에 도구 이름이 뜬다
[ ] Work에서 파일(문서·슬라이드) 미리보기가 된다
[ ] 회사 정책상 외부 연결이 금지되어 있다
```

## 이렇게 해 보세요

1. 위 점검표를 채웁니다.
2. 다음에 해당하면 **4장은 여기까지**로 둡니다. (개념만 익힌 날로.)
   - Plugins가 없다
   - 관리자가 연결을 막았다
   - 개인 메일·캘린더를 연습에 쓰고 싶지 않다
3. 대신 Chat 또는 Work에 **텍스트만**으로 같은 목적을 적습니다.

> 플러그인 없이: 필요한 메일 내용을 내가 붙여 넣겠다.  
> 너는 회신 초안과 체크리스트만 작성하고, 추측하지 마라.

4. 나중에 플러그인이 열리면 4-1의 `@` 연습만 되풀이하면 됩니다.

## 이 정도면 됐어요

「없다 = 실패」가 아니라 「없다 = 텍스트로 간다」고 말할 수 있으면 됩니다.

## 막히면

주변 사람이 쓰는 화면과 다르다고 불안해하지 마세요. 제품은 계정마다 다르게 보입니다.

공식 문서 [learn.chatgpt.com](https://learn.chatgpt.com/)과 자신의 화면이 어긋나면 **자신의 화면 + 이 책의 「없으면 건너뛰기」 규칙**을 우선합니다. 유튜브에 「ChatGPT Work 없음」을 검색해 천천히 따라가도 됩니다.
