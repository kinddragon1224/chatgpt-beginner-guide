# 4-3 · 없어도 되는 날, 있어도 되는 날

## 준비운동

기능을 「전부 설치하세요」라고 몰아붙이면, 안 열리는 화면 앞에서 나를 탓하기 쉽습니다. 교실에서도 「옆 사람 화면엔 있는데」 하며 주눅 드는 분이 있습니다.

4장에서 드릴 말은 하나입니다. **없어도 됩니다.** 없어도 이 책을 마칠 수 있습니다. 있으면 같은 일을 복사·붙여 넣기를 덜 하고 끝낼 뿐입니다.

## 어디 보면 되나

새 메뉴는 찾지 않습니다. 아래 네 줄만 봅니다.

```
[ ] Plugins 메뉴가 있다
[ ] @ 를 치면 도구 이름이 뜬다
[ ] Work에서 파일(문서·슬라이드) 미리보기가 된다
[ ] 회사 규칙상 다른 앱 연결이 막혀 있다
```

## 이렇게 해 보세요

1. 위 네 줄을 확인합니다.
2. 아래에 하나라도 해당하면 **4장은 여기까지**입니다. 뜻만 알고 넘어가는 날입니다.
   - Plugins가 없다
   - 관리자가 연결을 막았다
   - 내 메일·달력을 연습에 쓰고 싶지 않다
3. 대신 Chat이나 Work에 **글만** 붙여 넣고 같은 일을 부탁합니다.

> 플러그인 없이 하겠습니다. 필요한 메일 내용은 제가 붙여 넣겠습니다.  
> 답장 초안과 확인할 목록만 써 주세요. 추측하지 마세요.

4. 나중에 플러그인이 열리면 4-1의 `@` 연습만 다시 하면 됩니다.

## 이 정도면 됐어요

「없다 = 실패」가 아니라 「없다 = 글로 붙여 넣으면 된다」고 말할 수 있으면 됩니다.

## 막히면

옆 사람 화면과 달라도 걱정하지 마세요. 같은 ChatGPT라도 계정마다 다르게 보입니다.

공식 문서 [learn.chatgpt.com](https://learn.chatgpt.com/)과 내 화면이 다르면 **내 화면**과 이 책의 「없으면 건너뛰기」를 따릅니다. 유튜브에서 「ChatGPT Work 없음」을 검색해 천천히 따라가도 됩니다.
