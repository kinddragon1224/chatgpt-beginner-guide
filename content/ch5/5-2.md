# 5-2 · Chat / Work / Codex, 언제 무엇을

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt.md)

## 준비운동

도구가 늘수록 실력은 「많이 누르는 손」이 아니라 **고르는 판단**에서 갈립니다. 이 레슨은 책 전체의 회고입니다.

표를 외우지 말고, 자신의 최근 일 세 가지에 붙여 보세요. 회사 메신저 공지, 집 카톡 안내, 주보·학원 안내—그 셋을 떠올려도 됩니다.

## 어디 보면 되나

버튼을 더 누르지 않아도 됩니다. 아래처럼 최근 일 세 가지에만 라벨을 붙입니다.

```
내 일 ① ________ → Chat / Work / Codex
내 일 ② ________ → …
내 일 ③ ________ → …
```

## 이렇게 해 보세요

1. 공식 기준을 한국어로 압축한 아래 표를 읽습니다.

| 고르기 | 이럴 때 | 예 |
|--------|---------|----|
| **Chat** | 묻고, 탐색하고, 짧게 다듬을 때 | 질문, 웹 검색형 대화, 브레인스토름, 메시지 초안, 옵션 비교 |
| **Work** | 결과를 정의하고 **검토할 결과물**이 필요할 때 | 덱, 파일 분석, 보고서, 프로젝트 계획, 여러 도구에서 내용 모으기 |
| **Codex** | 개발자 도구·기술 세부·코드베이스가 필요할 때 (**데스크톱 앱에서만**) | 디버그, 테스트, PR 리뷰, 기능 구현 |

2. 판단 질문 세 개를 순서대로 적용합니다.
   - 대화만으로 끝나는가? → **Chat**
   - 열어 볼 파일·다단계 실행·검토 승인이 필요한가? → **Work**
   - 저장소·diff·테스트 같은 개발 흐름인가? → **Codex**
3. 최근 본인 일 세 가지에 라벨을 붙입니다.
4. 「전부 Work」로 몰리지 않았는지 점검합니다. 대화로 충분하면 Chat에서 시작하세요.

## 이 정도면 됐어요

셋을 **한 문장씩** 구분할 수 있고, 자신의 일 세 가지에 라벨을 붙였으면 이 책은 실습 목표를 달성한 겁니다.

- Chat: 묻고 답하고 짧은 글을 고치기 (채팅·이미지·검색)
- Work: 맡긴 뒤 검수하는 완성본 (문서·플러그인·자동화)
- Codex: 코드와 개발자 보기 (코드·개발)

## 막히면

경계가 애매하면 **더 가벼운 쪽(Chat)**부터 시작하세요. 부족하면 같은 주제를 Work으로 옮기면 됩니다.

Codex는 데스크톱 앱이 없으면 아예 없습니다. 그래도 Chat·Work만으로 일상·대부분의 지식 업무는 됩니다. 막히면 [부록](../appendix_stuck.md)을 보세요.
