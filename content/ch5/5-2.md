# 5-2 · Chat / Work / Codex, 언제 무엇을

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt)

## 준비운동

메뉴가 늘어도 잘 쓰는 사람은 많이 누르는 사람이 아니라 **잘 고르는 사람**입니다. 이 레슨은 책 전체를 되돌아보는 시간입니다.

표를 외우지 말고 요즘 내 일 세 가지에 붙여 보세요. 가족 카톡 안내, 동창회 순서표, 교회 주보 같은 일을 떠올려도 됩니다.

## 어디 보면 되나

버튼을 더 누르지 않아도 됩니다. 아래처럼 요즘 일 세 가지에 이름만 붙입니다.

```
내 일 ① ________ → Chat / Work / Codex
내 일 ② ________ → …
내 일 ③ ________ → …
```

## 이렇게 해 보세요

1. 공식 기준을 한국어로 줄인 아래 표를 읽습니다.

| 고르기 | 이럴 때 | 예 |
|--------|---------|----|
| **Chat** | 묻고, 찾아보고, 짧게 다듬을 때 | 질문, 웹 검색형 대화, 아이디어 모으기, 문자 초안, 여러 안 견주기 |
| **Work** | 결과를 정하고 **확인할 결과물**이 필요할 때 | 발표 자료, 파일 분석, 보고서, 계획표, 여러 곳의 내용 모으기 |
| **Codex** | 개발자 도구·기술 세부·프로그램 코드 전체를 다룰 때 | 오류 찾기(디버그), 테스트, 코드 검토, 기능 만들기 |

2. 고르는 질문 세 개를 차례로 던집니다.
   - 대화만으로 끝나는가? → **Chat**
   - 열어 볼 파일, 여러 단계, 확인 뒤 실행이 필요한가? → **Work**
   - 코드 저장소·바뀐 부분 비교(diff)·테스트 같은 개발 일인가? → **Codex**
3. 요즘 내 일 세 가지에 이름을 붙입니다.
4. 「전부 Work」로 몰리지 않았는지 봅니다. 대화로 충분하면 Chat에서 시작하세요.

## 이 정도면 됐어요

셋을 **한 문장씩** 구분할 수 있고, 내 일 세 가지에 이름을 붙였으면 됩니다.

- Chat: 묻고 답하고 짧은 글을 고치기 (채팅·이미지·검색)
- Work: 맡긴 뒤 확인하는 완성본 (문서·플러그인·자동화)
- Codex: 프로그램 코드를 다루는 개발 일

## 막히면

경계가 애매하면 **더 가벼운 쪽**(Chat)부터 시작하세요. 모자라면 같은 주제를 Work로 옮기면 됩니다.

Codex가 없어도 괜찮습니다. 무료·Go는 데스크톱 앱에서만 쓰고, Plus 이상은 웹·iOS에서도 씁니다. 생활과 일 대부분은 Chat·Work로 됩니다. 막히면 [부록 · 막히면 여기](../appendix_stuck.md)를 보세요.
