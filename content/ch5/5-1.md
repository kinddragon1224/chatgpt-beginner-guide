# 5-1 · Codex는 무엇인가

공식: [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt) · [Quickstart](https://learn.chatgpt.com/docs/quickstart)

## 준비운동

데스크톱 앱 왼쪽 위에 **Codex**가 보이면 「더 고급이니 이걸 써야지」 하는 분이 많습니다. 그런데 Codex는 쓰임이 다릅니다.

Codex는 **프로그램을 만드는 사람용**입니다. 프로그램 코드를 짜고, 고치고, 검사하는 일을 합니다. 카톡 안내·주보·모임 순서표는 2·3장에서 하면 됩니다.

오늘은 **맛보기**입니다. 코드는 건드리지 않습니다. 화면에 있는지 보고, 질문 하나로 말투와 화면이 어떻게 다른지만 봅니다.

## 어디 보면 되나

```
[왼쪽 위 제품 선택]
  ChatGPT | Codex   ← Codex를 잠시 선택

[Codex 쪽]
  New chat · (Quick chat 아이콘이 있을 수 있음)
  프로젝트·폴더·기술 세부 보기
```

이 연습(왼쪽 위에서 고르기, Quick chat)은 **데스크톱 앱에서만** 할 수 있습니다. 웹만 쓰면 그냥 5-2로 가면 됩니다.

## 이렇게 해 보세요

1. **ChatGPT 데스크톱 앱**을 엽니다. 앱이 없으면 읽기만 하고 넘어갑니다.
2. 왼쪽 위에서 **Codex**를 한 번 고릅니다.
3. 새 채팅(Quick chat이 있으면 그것)을 엽니다.
4. **파일을 건드리지 않는** 질문만 보냅니다. 폴더를 열 필요는 없습니다.

> 저는 프로그래밍을 하지 않습니다.  
> Codex가 ChatGPT Work와 어떻게 다른지, 처음 쓰는 사람 기준으로 다섯 줄로만 설명해 주세요.  
> 코드 예시는 넣지 마세요.

5. 답을 읽고 왼쪽 위에서 다시 **ChatGPT**로 돌아옵니다.
6. (선택) 같은 질문을 ChatGPT 쪽 **Chat**에 보내 말투와 길이만 견줘 봅니다.

## 이 정도면 됐어요

Codex가 **개발용**이라는 걸 알고, 내 화면에 있는지 없는지만 봤으면 됩니다. 폴더를 열거나 코드를 고치지 않습니다.

## 막히면

Codex가 없어도 실패가 아닙니다. **있으면 보고, 없으면 건너뛰세요.**

처음 열 때 전화번호 인증을 하라는 창이 뜰 수 있습니다. 문자 등으로 온 번호를 넣으면 됩니다. 내키지 않으면 닫고 5-2로 가도 됩니다.

실수로 내 컴퓨터 폴더를 열었으면 읽기만 하세요. 저장하거나 바꾸겠느냐는 승인 창은 누르지 않습니다. 회사 코드는 허락받은 환경에서만 다룹니다.
