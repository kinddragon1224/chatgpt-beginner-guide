# 3-2 · Work 첫걸음

공식: [Getting started with ChatGPT Work](https://learn.chatgpt.com/training/walkthroughs/getting-started)  
OpenAI 공식 연습 안내(Training walkthrough) 1편의 핵심만 옮겼습니다.

## 준비운동

Work는 **할 일이 여러 곳에 흩어져 있고, 끝에 확인할 결과물이 있어야 할 때** 씁니다.

동창회 총무를 떠올려 보세요. 날짜 의견은 단톡방에, 참석 인원은 문자에, 회비는 수첩에 있습니다. 기억만 믿고 공지를 쓰면 하나씩 빠집니다. 이럴 때 Work에 맡깁니다. 「이걸 모아서 공지 초안을 만들어 주세요. 보내기 전에 보여 주세요.」

공식 안내는 회사 예를 듭니다. 메일과 회사 메신저에 흩어진 인원·식단 정보를 Work가 모아서, 식당에 보낼 답장 초안을 만드는 식입니다.

오늘은 다른 앱을 연결하지 않습니다. 모아 둔 내용을 **붙여 넣기**만 합니다.

## 어디 보면 되나

```
[위쪽] Work
[입력창] 모아 둔 내용 + 받고 싶은 결과물 + 「보내기 전에 보여 주세요」
[결과] 공지 초안·목록 → 내가 확인 → 보내기는 내가 직접
```

## 이렇게 해 보세요

1. 위쪽에서 **Work**를 고릅니다. Work가 없으면 Chat에서 똑같이 해도 됩니다.
2. 흩어진 내용을 모아 아래처럼 보냅니다. 내용은 내 모임에 맞게 바꿉니다.

> 아래는 제가 모아 둔 내용입니다. 이 내용만 보고 동창회 모임 공지 초안을 만들어 주세요.  
> 모르는 것은 지어내지 말고 ‘확인 필요’라고 써 주세요.  
> ---  
> - 날짜 의견: 11월 둘째 토요일이 제일 많음  
> - 장소 후보: 시청역 근처 한식당 (이름은 아직 모름)  
> - 참석: 지금까지 12명, 더 올 수 있음  
> - 회비: 한 사람 3만 원, 총무 계좌로  
> ---  
> 받고 싶은 것: 단톡방에 올릴 공지 초안 하나, 아직 안 정해진 것 목록.  
> 제가 보내기 전에 초안만 보여 주세요.

3. 답이 오면 **내가 준 내용과 맞는지** 봅니다. 날짜·금액·장소가 바뀌지 않았는지 한 줄씩 짚어 봅니다.
4. 틀린 곳이 있으면 한 가지만 고쳐 달라고 합니다. 예: 「회비 줄만 다시 써 주세요. 나머지는 그대로 두세요.」
5. 공지는 내가 직접 단톡방에 붙여 넣어 보냅니다. Work가 대신 보내게 하지 않습니다.

## 이 정도면 됐어요

모아 둔 내용을 붙여 넣고 「보내기 전에 보여 주세요」까지 넣어 한 번 보냈습니다. 돌아온 초안을 내 눈으로 확인했으면 됩니다.

## 막히면

Work가 없으면 같은 부탁을 Chat에 보내세요. 글로 된 초안을 받으면 똑같이 연습한 겁니다.

Work가 오래 걸리거나 사용량 안내가 뜨면, 붙여 넣는 내용을 줄여서 다시 보냅니다.

목록 없이 긴 글만 오면 「안 정해진 것은 목록으로 따로 보여 주세요」라고 한 번 더 말합니다.

전화번호·계좌 번호·주민번호는 붙여 넣지 마세요. 연습은 가짜 이름, 가짜 숫자로 해도 됩니다.
