# 3-1 · Chat과 Work을 가르는 기준

공식: [Getting started with Work](https://learn.chatgpt.com/training/walkthroughs/getting-started)

## 준비운동

**요금제 한 줄:** 웹·앱에서 Work은 보통 Plus 이상입니다. 무료·Go면 Work이 없어도 정상. 그 경우 아래 연습은 Chat으로 같은 목표(완성본·부분 수정)를 하세요.

공식 안내의 핵심은 단순합니다.

- **Chat** — 채팅·이미지·검색. 생각·탐색·짧게 묻고 고치기.
- **Work** — 문서·플러그인·자동화. 여러 단계를 지나 **검토할 결과**가 필요할 때.

「왜 Work을 매사에 쓰지 않나」도 공식은 분명히 말합니다. 대화만으로 끝나면 Chat이 가볍고, Work의 긴 작업은 시간과 사용량을 더 쓸 수 있습니다.

쉽게 말하면, Chat은 옆에서 의논하는 쪽이고, Work은 「자료 모아서 초안까지 가져와 달라」고 맡긴 뒤 **결과물을 검수하는** 쪽입니다. Codex는 아직 열지 않습니다.

## 어디 보면 되나

```
[위쪽 전환]
  Chat | Work   ← Work을 눌러 있는지 확인 (길게 맡기지 않아도 됨)

[아래 입력창]
  결과물 형태 + 포함해야 할 것 + 검토 기준
```

웹·모바일·데스크톱 모두 Chat / Work 전환이 있습니다. 없으면 개념만 익히고 넘어가세요.

## 이렇게 해 보세요

1. 새 채팅을 연 뒤 **Work**을 선택해 봅니다. 입력창이 Chat과 비슷해 보여도, 여기는 결과물을 받는 화면입니다.
2. 아래 표만 읽습니다. 아직 보낼 필요는 없습니다.

| 상황 (한국 현장 예) | 선택 | 이유 한 줄 |
|------|------|------|
| 「부가세」가 뭔지 쉬운 설명 | Chat | 개념을 묻고 답하기 |
| 거래처에 보낼 세 문장 메일 초안 | Chat | 짧은 초안 |
| 메일함·슬랙에 흩어진 일정 모아 회신 초안 | Work | 흩어진 내용 모으기 + 검토할 결과 |
| 30분 세미나 진행 계획서 문서 | Work | 열어 볼 파일 |
| 「이 문장 더 공손하게」 | Chat | 한 가지 수정 |
| 분기 보고용 표·슬라이드 뼈대 | Work | 여러 단계의 결과물 |
| 코드 저장소·PR | Codex (5장) | 개발용 — 오늘은 건너뛰기 |

3. 최근 본인 일 하나를 떠올리고, 한 줄만 적습니다.  
   예: `팀 회식 장소 조사 → Chat` / `고객사 킥오프 1페이지 브리프 → Work` / `주일 안내 주보 초안 → Work`
4. 「애매하다」면 스스로에게 묻습니다. **열어 보고 구간만 고칠 파일이 필요한가?** 예면 Work, 아니면 Chat.

## 이 정도면 됐어요

「대화로 되나, 검토할 결과물이 필요하나」로 고를 수 있으면 됩니다. 긴 Work 작업은 아직 맡기지 않습니다. Work 버튼이 없어도 **개념만** 익히면 통과입니다.

## 막히면

Work 버튼이 없으면 요금제·지역·관리자 설정 때문일 수 있습니다. 그 경우 이 장은 개념만 읽고, 가능한 범위에서 Chat으로 초안 연습을 이어 가세요. 짧은 한 줄: **있으면 보고, 없으면 건너뛰세요.**

「만능 Work」로 모든 질문을 보내지 마세요. 짧은 질문은 Chat이 낫습니다.

Chat과 Work을 혼동해 같은 질문을 양쪽에 보내지 마세요. **한곳에만** 보내고 결과를 본 뒤 판단합니다.
