# 3-1 · Chat과 Work를 가르는 기준

공식: [Getting started with Work](https://learn.chatgpt.com/training/walkthroughs/getting-started)

## 준비운동

한 줄로 줄이면 이렇습니다.

Chat은 묻고 고칠 때. Work는 여러 단계를 거쳐 **확인할 결과물**이 있어야 할 때.

그래서 모든 질문을 Work에 보내지 않습니다. 말로 끝나는 일은 Chat이 가볍습니다. Work는 시간과 사용량을 더 씁니다.

Chat은 옆에 앉아 같이 의논하는 사람입니다. Work는 「자료 모아서 초안까지 만들어 와 주세요」 하고 일을 맡기는 사람입니다. 맡긴 뒤에는 결과물을 내가 확인합니다.

## 어디 보면 되나

```
[위쪽 전환]
  Chat | Work   ← Work를 눌러 보고, 있는지만 확인

[아래 입력창]
  만들 결과물 + 꼭 넣을 것 + 확인할 점
```

요금제에 따라 Chat / Work 전환이 보이기도 하고 안 보이기도 합니다. 없으면 아래 표만 읽고 넘어가세요.

## 이렇게 해 보세요

1. 새 채팅을 열고 위쪽에서 **Work**를 눌러 봅니다. 입력창은 Chat과 비슷해 보여도, 여기는 결과물을 받는 곳입니다. Work가 없으면 이 단계는 건너뜁니다.
2. 아래 표를 읽습니다. 아직 보내지 않아도 됩니다.

| 이런 일 | 고르기 | 이유 |
|------|------|------|
| 손주 생일 선물 추천 받기 | Chat | 묻고 답하면 끝 |
| 「기초연금」이 뭔지 쉽게 듣기 | Chat | 뜻을 묻기 |
| 병원 예약을 바꾸는 문자 세 줄 | Chat | 짧은 글 |
| 「이 문장 더 공손하게」 | Chat | 한 가지만 고치기 |
| 동창회 회비 정리표 | Work | 열어 보고 고칠 표 |
| 단톡방에 흩어진 모임 날짜·인원을 모아 공지문 만들기 | Work | 흩어진 내용 모으기 + 확인할 결과 |
| 업무라면: 분기 보고용 표와 발표 자료 뼈대 | Work | 여러 단계의 결과물 |

3. 요즘 내 일 하나를 떠올리고, Chat인지 Work인지 속으로 골라 봅니다. 예: 「가족 모임 식당 찾기 → Chat」, 「송년회 진행 순서표 → Work」.
4. 헷갈리면 이것 하나만 물어보세요. **열어 보고 일부만 고칠 파일이 필요한가?** 그렇다면 Work, 아니면 Chat입니다.

## 이 정도면 됐어요

「말로 끝나나, 파일이 필요하나」로 고를 수 있으면 됩니다. 긴 일은 아직 맡기지 않습니다. Work 버튼이 없어도 고르는 기준만 알면 통과입니다.

## 막히면

Work 버튼이 없으면 요금제·지역·관리자 설정 때문일 수 있습니다. 고장이 아닙니다. 3장은 Chat으로 하면 됩니다. 자세한 건 [3장 첫 쪽](index.md)을 보세요.

짧은 질문까지 Work에 보내지 마세요. 짧은 질문은 Chat이 빠릅니다.

같은 질문을 Chat과 Work에 한꺼번에 보내지 마세요. 한 곳에만 보내고, 답을 본 뒤 정합니다.
