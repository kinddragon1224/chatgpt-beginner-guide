# 3-3 · 첫 완성본을 받아 보기

공식: [Use ChatGPT — What ChatGPT Work can do](https://learn.chatgpt.com/docs/use-chatgpt)

## 준비운동

Work의 맛은 **열어 볼 수 있는 결과물**에 있습니다. 답이 문단으로만 오지 않고 문서·표·발표 자료 같은 파일로 옵니다. 그 파일을 보면서 「이 부분만 고쳐 주세요」 하고 말하면 됩니다.

2장에서는 짧은 글을 받았습니다. 이번에는 **제목이 나뉜 한두 쪽 문서**를 받습니다.

동창회 송년회 진행 순서표, 경로당 나들이 안내문, 교회 행사 운영안처럼 다른 사람에게 보여 줄 문서가 좋은 연습감입니다. 모르는 숫자는 ‘확인 필요’로 남기게 합니다.

## 어디 보면 되나

```
[Work]
[입력창] 무슨 문서 · 누가 읽나 · 들어갈 것 · 길이 · 하지 말 것
[결과] 미리보기 / 파일
[고치기] 「시간표만 다시」「표로 바꿔 주세요」 — 같은 대화에서
```

파일이 오면 미리보기로 열어 봅니다. 고칠 곳이 있으면 새 대화를 열지 말고 **같은 대화에서** 말합니다. 2-5에서 한 「한 가지씩」과 같습니다.

## 이렇게 해 보세요

1. 위쪽에서 **Work**를 고르고 새 작업을 시작합니다.
2. 아래를 내 모임에 맞게 바꿔 보냅니다.

**나쁜 예**

> 송년회 계획서 잘 좀 써 줘.

**좋은 예**

> 동창회 송년회 진행 순서표를 **문서**로 만들어 주세요.  
> 읽을 사람: 60대 동창 20명, 단톡방으로 받아 봄.  
> 들어갈 것: 날짜와 장소(‘확인 필요’로 두기), 시간표(10분 단위), 준비물, 회비 안내.  
> 길이: 한 쪽 이내로 짧게.  
> 모르는 숫자는 지어내지 말고 ‘확인 필요’라고 써 주세요.  
> 제가 바로 고칠 수 있게 제목을 나눠 주세요.

업무라면 제목만 바꿉니다. 예: 「직장인 30분 점심 세미나 진행 계획서」, 「학부모 설명회 20분 진행 순서」.

3. 결과가 오면 제목만 훑어보고, **한 가지만** 고쳐 달라고 합니다. 예: 「시간표만 표로 바꿔 주세요」, 「준비물에서 풍선은 빼 주세요」.
4. 마음에 들면 저장합니다. 결과에 **파일**이 보이면 눌러서 미리보기로 열고, 내려받기 버튼이 보이면 눌러 저장합니다. 버튼을 못 찾겠으면 글을 복사해 두어도 됩니다.

## 이 정도면 됐어요

Work에서 **문서를 한 번** 받고, 같은 대화에서 **한 곳을 고쳐** 달라고 해 봤으면 됩니다. 순서표는 초안입니다. 실제 시간·장소·담당자는 사람이 채웁니다.

## 막히면

Work가 없으면 같은 부탁을 Chat에 보냅니다. 파일 대신 제목이 나뉜 글로 받으면 됩니다.

파일 없이 긴 글만 오면 「문서 파일로 만들어 주세요」라고 한 번 더 말합니다.

고쳐 달라고 했는데 그대로면 범위를 좁힙니다. 「‘시간표’ 부분만 고쳐 주세요. 나머지는 그대로 두세요.」
