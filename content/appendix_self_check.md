# 부록 · 스스로 점검

따로 앱 없이 **종이 한 장**으로 끝내는 점검입니다. 각 장을 마칠 때마다 해당 칸만 읽고, 되면 ✓, 안 되면 「다음에」라고 적으세요. 완벽 점수가 목표가 아닙니다. **오늘 한 행동**이 남는 것이 목표입니다.

---

## 장별 체크리스트

### 0장 · 준비

- [ ] 웹 또는 앱 중 오늘 쓸 입구를 정했다  
- [ ] 계정·결제는 본인·회사 정책에 맡기고, 책 때문에 결제하지 않았다  
- [ ] 화면 캡처가 없어도 글 설명만으로 메뉴·버튼을 찾을 수 있다  

### 1장 · 빠르게 시작하기

- [ ] 로그인까지 했다 (또는 이미 되어 있었다)  
- [ ] Chat / Work / Codex를 **손가락으로 가리킬 수 있다** (없어도 ‘없음’을 확인)  
- [ ] 새 채팅을 열고 **문장 하나를 보내** 답을 받았다  
- [ ] 「이 정도면 됐어요」에서 멈췄다  

### 2장 · Chat

- [ ] 2-1: 목적·조건·형식이 있는 질문을 보냈다  
- [ ] 2-2: 내 수준을 밝힌 설명 요청을 했다  
- [ ] 2-3: 넓은 목록 → 기준으로 줄이기를 했다  
- [ ] 2-4: 짧은 초안을 받고 사실을 눈으로 확인했다  
- [ ] 2-5: **같은 대화**에서 수정을 한 가지씩 했다  
- [ ] 나쁜 프롬프트(「알려 줘」「더 좋게」)를 피했다  

### 3장 · Work

- [ ] 3-1: 최근 일 하나를 Chat/Work 중 하나로 골라 봤다  
- [ ] 3-2: 「보내기 전에 보여 주세요」를 넣어 부탁했다 (연결 없이 붙여 넣기로)  
- [ ] 3-3: 문서를 받고 한 곳만 고쳐 달라고 했다  
- [ ] 3-4: 한 장 요약 → Work 결과물 → 한 곳 고치기까지 했다  
- [ ] 짧은 질문을 Work에 습관적으로 보내지 않았다  

### 4장 · 플러그인·스킬·슬라이드

- [ ] 플러그인 = 능력·연결, 스킬 = 반복 방식이라고 구분했다  
- [ ] Plugins가 없으면 4-3 「없으면 건너뛰기」를 적용했다  
- [ ] 슬라이드·문서를 만들면 **검토 후** 공유한다  

### 5장 · Codex 맛보기 · 회고

- [ ] Codex는 개발용이고 **데스크톱 앱에서만** 있음을 이해했다 (웹만이면 ‘없음’ 확인)  
- [ ] 「고급이니 Codex」습관을 버렸다  
- [ ] Chat / Work / Codex 중 **오늘 기본값**을 한 줄로 정했다

## 오늘 한 일 · 기록 틀

아래를 복사해 날짜별로 적으세요. 하루 한 줄이면 됩니다.

```
날짜: YYYY-MM-DD (예: 2026-09-21)
레슨: (예: 2-4)
어디를 썼나: Chat / Work / Codex / 없음
한 행동: (예: 워크숍 안내 문자 초안 1통 / 주보 안내 한 단락)
판단: (예: 짧은 초안이라 Chat)
결과 활용: (예: 사실 확인 후 카톡 발송)
막힌 점: (예: 없음 / Work 버튼 없음)
다음에: (예: 2-5에서 말투만 수정)
```

### 주간 되돌아보기 (선택, 일요일 5분)

- 이번 주 Chat을 쓴 횟수 / Work를 쓴 횟수: ____ / ____  
- 「새 채팅 남발」을 줄였는가: 예 / 아니오  
- 사실 확인을 건너뛴 적이 있는가: 예 / 아니오 → 예라면 어떤 주제인가  
- 한 줄 교훈: ________________________________

## 되돌아보기 순서 (도구 없이)

1. **행동** — 레슨의 「이렇게 해 보세요」를 끝까지  
2. **기록** — 위 기록 한 줄  
3. **점검** — 장별 체크리스트 ✓  
4. **조정** — 「다음에」만 다음 공부의 첫 줄로  

점수가 오르는 앱이 없어도, 기록이 쌓이면 「나는 Chat을 과하게 쓴다」「한 장 요약 없이 Work에 바로 간다」가 보입니다. 그 문장이 다음 주의 교재입니다.

막히면 [막히면 여기](appendix_stuck.md)로 가세요.
