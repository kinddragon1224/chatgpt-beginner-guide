# 부록 · 스스로 점검

**종이 한 장**이면 됩니다. 장을 마칠 때마다 그 장 칸만 읽고, 했으면 ✓, 못 했으면 「다음에」라고 쓰세요. 점수는 중요하지 않습니다. **오늘 한 가지를 해 봤는지**만 봅니다.

---

## 장마다 되돌아보기

### 0장 · 준비

- [ ] 오늘 쓸 기기를 하나 정했다  
- [ ] 가입에 쓸 이메일을 정했다  
- [ ] 책 때문에 결제하지 않았다 (무료라면 1·2장부터)  

### 1장 · 빠르게 시작하기

- [ ] 로그인까지 했다 (또는 이미 되어 있었다)  
- [ ] Chat / Work / Codex를 **손가락으로 가리킬 수 있다** (없으면 ‘없음’을 확인)  
- [ ] 새 채팅을 열고 **문장 하나를 보내** 답을 받았다  
- [ ] 다음 날 왼쪽 대화 목록에서 어제 대화를 찾았다  

### 2장 · Chat

- [ ] 2-1: 목적·조건·형식이 있는 질문을 보내고, 답을 복사해 봤다  
- [ ] 2-2: 내 수준을 밝히고 설명을 부탁했다  
- [ ] 2-3: 넓게 받은 뒤 내 기준으로 세 개로 줄였다  
- [ ] 2-4: 짧은 초안을 받고 날짜·이름을 눈으로 확인했다  
- [ ] 2-5: **같은 대화**에서 한 가지씩 고쳤다  
- [ ] 2-6: 성격과 맞춤 지시를 저장하고 새 채팅에서 말투를 봤다 (메뉴가 없으면 ‘없음’)  
- [ ] 2-7: 그림 한 장을 받고 한 곳을 고쳐 저장했다 (안 되면 ‘안 됨’)  

### 3장 · Work

- [ ] 3-1: 요즘 일 하나를 Chat/Work 중 하나로 골라 봤다  
- [ ] 3-2: 「보내기 전에 보여 주세요」를 넣어 부탁했다 (연결 없이 붙여 넣기로)  
- [ ] 3-3: 문서를 받고 한 곳만 고쳐 달라고 했다  
- [ ] 3-4: 한 장 요약 → Work 결과물 → 한 곳 고치기까지 했다  
- [ ] 짧은 질문까지 Work에 보내지 않았다  

### 4장 · 플러그인·스킬·슬라이드

- [ ] 플러그인은 다른 앱과 잇기, 스킬은 내 방식 저장하기라고 구분했다  
- [ ] 4-2: 메모 → 문서 → 슬라이드 순서로 받아 봤다 (Work가 없으면 글 개요로)  
- [ ] Plugins가 없으면 4-3의 「없으면 건너뛰기」를 따랐다  

### 5장 · Codex 맛보기 · 회고

- [ ] Codex는 개발용이고, 이 책의 연습은 **데스크톱 앱에서** 한다는 것을 알았다 (웹만 쓰면 ‘화면에 없음’ 확인)  
- [ ] 「고급이니 Codex」 하는 습관을 버렸다  
- [ ] 요즘 내 일 세 가지에 Chat / Work / Codex를 붙여 봤다

## 하루 한 줄

이 책에서 무언가를 적는 곳은 여기 한 곳뿐입니다. 공부한 날 한 줄만 쓰세요.

```
날짜 / 레슨 / 한 일 / 다음에 할 것
예) 9월 30일 / 2-4 / 병원 예약 변경 문자 초안 / 2-5에서 말투만 고치기
```

### 일주일에 한 번 (하고 싶을 때만)

- 이번 주 Chat을 쓴 날 / Work를 쓴 날: ____ / ____  
- 새 채팅을 너무 자주 열지 않았나: 예 / 아니오  
- 사실 확인을 건너뛴 적이 있나: 예 / 아니오  

한 줄씩 쌓이면 「나는 Chat만 쓴다」「확인을 자꾸 건너뛴다」 같은 버릇이 보입니다. 다음 주에는 그 하나만 고치면 됩니다.
