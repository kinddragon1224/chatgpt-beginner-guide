# 1-1 · 웹으로 갈지, 앱으로 갈지

공식: [Quickstart](https://learn.chatgpt.com/docs/quickstart)

## 준비운동

첫날 제일 흔한 실수입니다. 웹도 깔고 앱도 깔고, 둘 다 만지작거리는 것.

카톡을 폰·PC·웹에서 한꺼번에 열어 두면 어디가 최신인지 헷갈리죠. ChatGPT도 마찬가지입니다. **오늘 쓸 길을 하나만** 고르세요.

공식 안내(Quickstart)는 오래 쓸 때 **컴퓨터 앱**을 권합니다. 다만 오늘 목표는 「길 하나 정하기」입니다. **웹이든 앱이든 하나만** 고르세요. 둘 다 열어 두면 헷갈립니다.

## 어디 보면 되나

**웹을 고른 경우**

```
[브라우저 주소창]
chatgpt.com
        ↓
[로그인 / 시작 버튼이 보이는 첫 화면]
```

**컴퓨터 앱을 고른 경우**

```
[ChatGPT 다운로드 페이지]
  → 운영체제에 맞는 설치 파일
        ↓
[설치 후 앱 아이콘으로 실행]
```

**휴대전화 앱을 고른 경우(앱을 쓸 때만)**

```
[앱 상점 검색] → ChatGPT → [설치]
        ↓
[홈 화면의 ChatGPT 아이콘]
```

## 이렇게 해 보세요

앱을 쓰려면 ChatGPT 다운로드 페이지에서 운영체제에 맞는 설치 파일을 받습니다. 오늘은 설치가 부담이면 **웹(chatgpt.com)** 만으로 다음 레슨까지 가도 됩니다.

**웹**

1. 브라우저를 엽니다.
2. 주소창에 `chatgpt.com`을 넣고 Enter를 누릅니다.
3. ChatGPT 이름이나 Log in / Sign up 버튼이 보이면, 웹 길에 들어온 겁니다.

**컴퓨터 앱(선택)**

1. 브라우저에서 ChatGPT 다운로드 페이지를 엽니다.
2. 쓰는 컴퓨터(Windows / Mac)에 맞는 파일을 받아 설치합니다.
3. 설치한 앱을 실행합니다.

**휴대전화 앱(선택)**

1. App Store 또는 Google Play를 엽니다.
2. `ChatGPT`를 검색해 공식 앱을 설치합니다.
3. 홈 화면 아이콘으로 실행합니다.

## 이 정도면 됐어요

오늘 쓸 **하나의 길**(웹 또는 컴퓨터 앱 또는 휴대폰 앱)이 열려 있고, 화면에 ChatGPT 이름이 보이면 됩니다. 로그인은 다음 레슨입니다.

## 막히면

주소 철자가 틀리면 다른 사이트로 갑니다. `chatgpt.com`만 다시 보세요.

회사망이 막으면 개인 네트워크에서 웹으로 시도하거나, 허용된 기기만 쓰세요.

앱 설치가 부담이면 **웹만** 쓰세요. 유튜브에 「ChatGPT 웹 시작」을 검색해 천천히 따라가도 됩니다.
