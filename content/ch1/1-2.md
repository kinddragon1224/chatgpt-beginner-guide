# 1-2 · 가입·로그인

공식: [Quickstart](https://learn.chatgpt.com/docs/quickstart)

## 준비운동

은행 앱을 구경만 하는 것과, 계좌에 들어가 이체하는 것은 다릅니다.

ChatGPT도 둘러볼 수는 있어도, 대화를 이어 가려면 **계정에 로그인**해야 합니다. 오늘은 가입 또는 로그인만 합니다.

요금제 비교, 플러그인, 새 프로젝트는 건드리지 마세요.

## 어디 보면 되나

```
[화면 가운데 또는 오른쪽 위]
  Log in  /  로그인
  Sign up /  가입·시작
```

로그인 뒤에는 대개 **아래쪽 입력창**(글을 적는 칸)이 나옵니다. 그 칸이 보이면 들어온 겁니다.

## 이렇게 해 보세요

1. 1-1에서 연 화면을 그대로 둡니다.
2. 계정이 있으면 **로그인(Log in)**을 누릅니다.
3. 계정이 없으면 **가입(Sign up)**을 누릅니다.
4. 이메일 또는 안내된 방식(Google 등)으로 본인 확인을 마칩니다. 구글 계정이면 편합니다.
5. 비밀번호를 정하거나, 기존 비밀번호를 입력합니다.
6. Continue / 확인을 눌러 마칩니다.

## 이 정도면 됐어요

채팅 **입력창**이 보이면 로그인에 성공한 겁니다. 메뉴를 다 열어 볼 필요는 없습니다.

## 막히면

- Log in = 로그인, Sign up = 가입입니다. 영어 화면이어도 하는 일은 같습니다.
- 비밀번호를 잊었으면 Forgot password / 비밀번호 찾기만 쓰세요.
- 인증 메일이 없으면 스팸함·프로모션함을 보세요. 회사 메일이면 필터에 걸릴 때가 많습니다.
- 휴대전화 앱도 버튼 이름은 같습니다. 같은 순서로 하면 됩니다.
- 그래도 막히면 유튜브에 「ChatGPT 가입」을 검색해 천천히 따라가 보세요.
