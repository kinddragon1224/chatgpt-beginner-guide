# 1-4 · 새 채팅 열기

공식: [Quickstart](https://learn.chatgpt.com/docs/quickstart)

## 준비운동

카톡에서 「새 채팅」을 열어야 상대에게 첫 말을 건네듯, ChatGPT도 **빈 대화방**이 있어야 첫 문장을 보냅니다.

아래 입력창이 비어 있어야 합니다. Work으로 바꾸거나 파일을 올리지 마세요. **빈 칸을 여는 방법**만 익힙니다.

## 어디 보면 되나

```
[왼쪽 위 또는 사이드 상단]
  New chat / 새 채팅 / +
            ↓
[화면 아래]
  [ 입력창 _______________ ]  [보내기 →]
```

이미 빈 입력창이 열려 있다면, 새 채팅을 또 누를 필요는 없습니다.

## 이렇게 해 보세요

1. 위쪽이 **Chat**인지 확인합니다.
2. 왼쪽 또는 위에서 **New chat**(새 채팅, +)을 찾습니다.
3. 한 번 누릅니다.
4. 아래 입력창이 비어 있는지 봅니다. 「무엇이든 물어보세요」 같은 안내 문구가 있어도 정상입니다.

## 이 정도면 됐어요

보낸 글이 아직 없고, **빈 입력창**만 보이면 새 채팅이 열린 겁니다.

## 막히면

버튼이 「+」만 있어도 같은 역할입니다. 사이드가 접혀 있으면 펼치세요.

그래도 New chat이 안 보이면, 이미 열린 입력창에 바로 적어도 됩니다. 글을 넣을 칸만 있으면 됩니다.
