# 1장 · 빠르게 시작하기

**ChatGPT를 열고, 문장 하나를 보냅니다.**

공식 안내: [Quickstart](https://learn.chatgpt.com/docs/quickstart)

ChatGPT를 「언젠가」가 아니라 「오늘」 쓰려면, 거창한 팁보다 먼저 말을 걸어 봅니다.

| 레슨 | 내용 |
|------|------|
| 1-1 | 웹으로 갈지, 앱으로 갈지 |
| 1-2 | 가입·로그인 |
| 1-3 | Chat / Work / Codex 이름표 찾기 |
| 1-4 | 새 채팅 열기 |
| 1-5 | 첫 문장 보내기 |
| 1-6 | 답이 오면 오늘 끝 |

각 레슨은 한 호흡입니다. 1-6에서 답이 보이면 1장은 완료입니다. Chat과 Work을 비교하는 일은 2장·3장으로 미룹니다.
