# 1-3 · Chat / Work / Codex 이름표

공식: [Quickstart](https://learn.chatgpt.com/docs/quickstart) · [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt.md)

## 준비운동

ChatGPT 안에는 쓰임새가 다른 모드가 있습니다. 오늘은 **이름이 어디에 있는지**만 익힙니다.

- **Chat** — 채팅·이미지·검색. 묻고 생각하기. (무료·Go·Plus·Pro 공통)
- **Work** — 문서·플러그인·자동화. 검토할 결과물. (**웹·앱에서는 보통 Plus 이상.** 무료·Go면 안 보여도 정상)
- **Codex** — 코드·개발. 데스크톱 앱에서만. 있으면 보고, 없으면 건너뛰세요.

깊게 쓰지 않습니다. Work이 없어도 이 레슨은 통과입니다.

## 어디 보면 되나

데스크톱·웹 화면은 조금씩 다르지만, 대개 아래 구조입니다.

```
[왼쪽 위 · 제품]
  ChatGPT | Codex

[ChatGPT를 고른 뒤 · 위쪽 전환]
  Chat | Work

[사이드]
  New chat · Projects · Plugins · 최근 대화 …
```

모바일에서는 화면 **맨 위 드롭다운**에서 Chat / Work을 고르는 경우가 많습니다. **Codex는 모바일·웹에 없습니다.** 데스크톱 앱에서만 고릅니다.

## 이렇게 해 보세요

1. 로그인한 뒤 화면 **위쪽**과 **왼쪽**을 한 바퀴만 훑습니다.
2. **Chat** 글자(또는 대화·채팅에 가까운 이름)를 찾습니다.
3. **Work**(또는 ChatGPT Work)를 찾습니다.
4. **Codex**가 보이면 위치만 기억합니다. 없어도 다음으로 갑니다.
5. Plugins가 안 보이면 이 레슨에서는 그냥 넘어갑니다.

## 이 정도면 됐어요

「Chat은 여기, Work은 여기」라고 **손가락으로 가리킬 수 있으면** 됩니다. Codex·Plugins는 없어도 됩니다.

## 막히면

왼쪽 메뉴가 접혀 있으면 ≡ 또는 화살표로 한 번만 펼치세요.

글자가 번역·개편되어도 「묻기」에 가까운 쪽이 Chat, 「완성본·작업」에 가까운 쪽이 Work입니다.

Work·Codex가 안 보이면 고장이 아닙니다.

- **무료·Go** → 웹·휴대폰에 Work이 없습니다(데스크톱은 제한적으로 있을 수 있음). Chat만 있으면 됩니다.
- **Plus·Pro** → Work이 보여야 하는데 아직 없으면, 롤아웃 중이거나 잠시 후 다시 보면 됩니다.
- **Codex** → 웹·휴대폰에서는 없고, **데스크톱 앱에서만** 고릅니다.

짧은 한 줄: **있으면 보고, 없으면 건너뛰세요.**
